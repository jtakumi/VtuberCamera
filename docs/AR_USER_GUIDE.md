# AR機能使用方法ガイド

## 概要

VTuber Camera アプリのAR（拡張現実）機能を使用して、VRMアバターと一緒に写真を撮影する方法を説明します。このガイドに従って、魅力的なAR写真を作成しましょう。

## 事前準備

### 必要な権限
AR機能を使用する前に、以下の権限を許可してください：

1. **カメラ権限**: AR撮影に必要
2. **ストレージ権限**: 写真保存に必要
3. **ARCore権限**: AR機能に必要

### デバイス要件
- **ARCore対応デバイス**: [ARCore対応デバイス一覧](https://developers.google.com/ar/devices)を確認
- **Android 7.0以上**: API Level 25以上
- **RAM**: 3GB以上推奨
- **ストレージ**: 1GB以上の空き容量

### ARCoreのインストール
1. Google Play StoreでARCoreを検索
2. ARCoreをインストール
3. 最新版に更新

## VRMアバターの準備

### アバターの読み込み
1. **アプリを起動**
2. **「アバターライブラリ」**をタップ
3. **「VRMファイルを追加」**をタップ
4. **ファイルピッカー**からVRMファイルを選択
5. **読み込み完了**を待つ

### アバターの管理
- **名前変更**: アバターを長押しして「名前変更」
- **削除**: アバターを長押しして「削除」
- **プレビュー**: アバターをタップしてプレビュー表示

## AR撮影の基本操作

### ARモードの開始
1. **カメラ画面**を開く
2. **「ARモード」**ボタンをタップ
3. **アバター選択**画面でアバターを選択
4. **ARカメラ**が起動

### アバターの配置
1. **画面をタップ**してアバターを配置
2. **平面検出**が完了するまで待機
3. **アバターが表示**されることを確認

### 基本的な操作方法

#### 位置の調整
- **ドラッグ**: アバターを移動
- **上下移動**: 2本指で上下にドラッグ
- **前後移動**: ピンチイン/アウト

#### サイズの調整
- **ピンチジェスチャー**: 拡大・縮小
- **サイズボタン**: 画面下部のサイズ調整ボタン
- **リセット**: 「リセット」ボタンで初期サイズに戻す

#### 回転の調整
- **回転ジェスチャー**: 2本指で回転
- **回転ボタン**: 画面下部の回転ボタン
- **正面向き**: 「正面」ボタンでカメラ方向に向ける

## 高度な機能

### 表情の変更
1. **表情メニュー**をタップ
2. **利用可能な表情**から選択
3. **リアルタイムプレビュー**で確認
4. **適用**をタップ

#### 基本表情
- **通常**: デフォルトの表情
- **笑顔**: 喜びの表情
- **困り顔**: 困った表情
- **驚き**: 驚いた表情
- **ウィンク**: 片目をつぶる

### ポーズの変更
1. **ポーズメニュー**をタップ
2. **利用可能なポーズ**から選択
3. **プレビュー**で確認
4. **適用**をタップ

#### 基本ポーズ
- **立ちポーズ**: 自然な立ち姿
- **手を振る**: 挨拶のポーズ
- **ピースサイン**: Vサインのポーズ
- **お辞儀**: 礼をするポーズ

### 照明の調整
1. **照明メニュー**をタップ
2. **設定項目**を調整：
   - **明度**: 全体の明るさ
   - **色温度**: 光の色味
   - **影の強さ**: 影の濃さ
3. **自動調整**: 環境に応じた自動設定

## 撮影のコツ

### 良い写真を撮るために

#### 照明環境
- **明るい場所**での撮影を推奨
- **直射日光**は避ける
- **均等な照明**が理想的
- **逆光**に注意

#### アバターの配置
- **適切な距離**: 1-3メートルが最適
- **安定した平面**: テーブルや床を活用
- **背景**: シンプルな背景が効果的
- **構図**: 三分割法を意識

#### デバイスの持ち方
- **両手でしっかり**と持つ
- **手ブレ**を最小限に
- **水平**を保つ
- **ゆっくり**とした動作

### 撮影シーン別のコツ

#### 室内撮影
- **十分な照明**を確保
- **白い壁**を背景に活用
- **窓際**の自然光を利用
- **照明設定**を調整

#### 屋外撮影
- **日陰**での撮影を推奨
- **風の影響**に注意
- **地面の平面**を確認
- **周囲の安全**を確保

## トラブルシューティング

### よくある問題と解決方法

#### アバターが表示されない
1. **平面検出**を再実行
2. **照明環境**を改善
3. **アプリの再起動**
4. **ARCoreの更新**

#### 動作が重い
1. **他のアプリ**を終了
2. **アバターの品質**を下げる
3. **デバイスの再起動**
4. **ストレージの確保**

#### 撮影できない
1. **権限設定**を確認
2. **ストレージ容量**を確認
3. **カメラアプリ**の終了
4. **デバイスの再起動**

詳細なトラブルシューティングについては、[トラブルシューティングガイド](TROUBLESHOOTING.md)を参照してください。

## 設定とカスタマイズ

### パフォーマンス設定
- **品質レベル**: 高/中/低から選択
- **フレームレート**: 30fps/60fps
- **解像度**: デバイスに応じて調整
- **バッテリー最適化**: 長時間使用時に有効

### UI設定
- **ボタンサイズ**: 大/中/小
- **透明度**: UI要素の透明度調整
- **配置**: ボタンの配置カスタマイズ
- **ヘルプ表示**: 初心者向けガイド表示

## 写真の管理

### 撮影した写真
- **自動保存**: Pictures/VTuberCamera/AR/
- **メタデータ**: アバター情報を含む
- **共有機能**: SNSへの直接共有
- **編集機能**: 基本的な画像編集

### ギャラリー機能
- **AR写真の識別**: 特別なマークで表示
- **アバター情報**: 使用したアバターの表示
- **撮影設定**: 撮影時の設定情報
- **お気に入り**: 気に入った写真をマーク

## 安全な使用について

### プライバシー保護
- **位置情報**: 必要時のみ使用
- **写真データ**: ローカル保存
- **アバターデータ**: 外部送信なし
- **使用統計**: 匿名化されたデータのみ

### 使用時の注意
- **周囲の安全**: 歩きながらの使用は避ける
- **プライバシー**: 他人の写り込みに注意
- **バッテリー**: 長時間使用時は充電を確保
- **発熱**: 過度な使用は避ける
