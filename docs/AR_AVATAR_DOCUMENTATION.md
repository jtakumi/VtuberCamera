## クイックスタートガイド

### 初回セットアップ
1. **権限の許可**: カメラ、ストレージ、ARCoreの権限を許可
2. **ARCoreのインストール**: Google Play StoreからARCoreをインストール
3. **VRMファイルの準備**: [VRM要件](VRM_REQUIREMENTS.md)に従ってファイルを準備
4. **アバターの読み込み**: アプリでVRMファイルを読み込み

### 基本的な使用手順
1. **ARモードの開始**: カメラ画面でARモードを選択
2. **アバターの選択**: ライブラリからアバターを選択
3. **アバターの配置**: 画面をタップしてアバターを配置
4. **調整と撮影**: 位置・サイズ・表情を調整して撮影

## 技術仕様

### システム要件
- **Android**: 7.0以上（API Level 25+）
- **ARCore**: 対応デバイス必須
- **RAM**: 3GB以上推奨
- **ストレージ**: 1GB以上の空き容量

### VRMファイル仕様
- **形式**: VRM 0.0 / VRM 1.0
- **最大サイズ**: 50MB
- **推奨ポリゴン数**: 10,000以下
- **推奨テクスチャ**: 1024x1024px以下

### パフォーマンス目標
- **フレームレート**: 30fps以上
- **起動時間**: 3秒以内
- **メモリ使用量**: 500MB以下
- **バッテリー効率**: 標準カメラアプリの90%以上

## サポート情報

### よくある質問（FAQ）

**Q: どのVRMファイルが使用できますか？**
A: VRM 0.0およびVRM 1.0形式のファイルが使用できます。詳細は[VRM要件](VRM_REQUIREMENTS.md)を参照してください。

**Q: ARモードが使用できません**
A: デバイスがARCore対応か確認し、ARCoreがインストールされているか確認してください。詳細は[トラブルシューティング](TROUBLESHOOTING.md)を参照してください。

**Q: アバターの表情が変わりません**
A: VRMファイルにBlendShapeが含まれているか確認してください。詳細は[VRM要件](VRM_REQUIREMENTS.md)の表情制御セクションを参照してください。

**Q: 動作が重いです**
A: 品質設定を下げるか、より軽量なVRMファイルを使用してください。詳細は[トラブルシューティング](TROUBLESHOOTING.md)のパフォーマンス問題セクションを参照してください。
