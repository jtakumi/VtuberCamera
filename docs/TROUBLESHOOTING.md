## VRMファイル関連の問題

### VRMファイルが読み込めない

#### 症状
- ファイル選択後にエラーメッセージが表示される
- 読み込み中に停止する
- アバターが表示されない

#### 原因と解決方法

**1. ファイル形式の問題**
```
原因: 対応していないファイル形式
解決方法:
- VRM 0.0またはVRM 1.0形式を使用
- ファイル拡張子が.vrmであることを確認
- 他の3D形式（.fbx, .obj等）は非対応
```

**2. ファイルサイズの問題**
```
原因: ファイルサイズが50MBを超えている
解決方法:
- VRMファイルを最適化して50MB以下にする
- ポリゴン数を削減する
- テクスチャ解像度を下げる
- 不要なデータを削除する
```

**3. ファイル破損の問題**
```
原因: VRMファイルが破損している
解決方法:
- 元のファイルから再出力する
- 別のVRMファイルで動作確認する
- VRMファイルの整合性をチェックする
```

**4. メモリ不足の問題**
```
原因: デバイスのメモリが不足している
解決方法:
- 他のアプリを終了する
- デバイスを再起動する
- より軽量なVRMファイルを使用する
```

### 表情やポーズが動作しない

#### 症状
- 表情選択メニューが空
- 表情を選択してもアバターが変化しない
- ポーズが適用されない

#### 解決方法

**1. BlendShapeの確認**
```
確認項目:
- VRMファイルにBlendShapeが含まれているか
- BlendShapeの命名規則が正しいか
- ウェイト値が適切に設定されているか

対処方法:
- VRoid Studioで表情を再設定
- BlendShapeの命名を標準規則に合わせる
- ウェイト値を0-1の範囲で設定
```

**2. ボーン構造の確認**
```
確認項目:
- ヒューマノイドボーンが正しく設定されているか
- ボーンの階層構造が適切か
- IKチェーンが正しく構成されているか

対処方法:
- Unityでヒューマノイド設定を確認
- ボーン構造を標準規格に合わせる
- 不要なボーンを削除する
```

## AR機能の問題

### ARモードが開始できない

#### 症状
- ARモードボタンをタップしても反応しない
- 「ARCoreが利用できません」エラー
- カメラプレビューが表示されない

#### 解決方法

**1. ARCore関連の問題**
```
確認項目:
- ARCoreがインストールされているか
- ARCoreが最新版か
- デバイスがARCore対応か

対処方法:
1. Google Play StoreでARCoreを検索
2. ARCoreをインストール/更新
3. デバイス対応状況を確認
4. 非対応の場合は2Dモードを使用
```

**2. 権限の問題**
```
確認項目:
- カメラ権限が許可されているか
- ARCore権限が許可されているか

対処方法:
1. 設定 > アプリ > VTuber Camera > 権限
2. カメラとARCoreの権限を有効化
3. アプリを再起動
```

### アバターが表示されない

#### 症状
- ARモードは開始するがアバターが見えない
- 平面検出ができない
- アバターが床に埋まる

#### 解決方法

**1. 平面検出の問題**
```
原因: 適切な平面が検出されない
対処方法:
- 明るい場所で使用する
- テクスチャのある平面を使用
- デバイスをゆっくり動かす
- 床や机などの安定した平面を選ぶ
```

**2. 照明環境の問題**
```
原因: 照明が不十分
対処方法:
- 室内照明を明るくする
- 窓際の自然光を利用する
- 直射日光は避ける
- 均等な照明環境を作る
```

**3. アバター配置の問題**
```
原因: アバターが適切な位置に配置されない
対処方法:
- 画面をタップして再配置
- 高さ調整ボタンを使用
- リセットボタンで初期位置に戻す
- 距離を1-3メートルに調整
```

### トラッキングが不安定

#### 症状
- アバターが揺れる
- 位置がずれる
- 突然消える

#### 解決方法

**1. 環境要因の改善**
```
対処方法:
- 手ブレを最小限にする
- 急激な動きを避ける
- 照明を安定させる
- 反射する表面を避ける
```

**2. デバイス性能の最適化**
```
対処方法:
- 他のアプリを終了する
- 品質設定を下げる
- フレームレートを30fpsに設定
- バックグラウンドアプリを制限
```

## パフォーマンスの問題

### 動作が重い・カクつく

#### 症状
- フレームレートが低い
- 操作の反応が遅い
- アプリが頻繁に停止する

#### 解決方法

**1. 設定の最適化**
```
推奨設定:
- 品質レベル: 中または低
- フレームレート: 30fps
- 解像度: 自動調整
- バッテリー最適化: 有効
```

**2. デバイス最適化**
```
対処方法:
- 不要なアプリを終了
- ストレージ容量を確保（1GB以上）
- デバイスを再起動
- 冷却のため使用を一時停止
```

**3. VRMファイルの最適化**
```
推奨仕様:
- ポリゴン数: 5,000以下
- テクスチャ: 512x512px以下
- マテリアル数: 5個以下
- ボーン数: 30個以下
```

### バッテリー消費が激しい

#### 症状
- 短時間でバッテリーが減る
- デバイスが発熱する
- 充電しながらでも減る

#### 解決方法

**1. 省電力設定**
```
設定変更:
- バッテリー最適化を有効
- 画面の明度を下げる
- フレームレートを30fpsに設定
- 不要な機能を無効化
```

**2. 使用方法の改善**
```
対処方法:
- 連続使用時間を制限（30分以内）
- 充電しながらの使用を避ける
- 発熱時は使用を停止
- 省電力モードを活用
```

## 権限とデバイス対応の問題

### 権限エラー

#### 症状
- 「カメラ権限が必要です」エラー
- 「ストレージアクセスが拒否されました」エラー
- 機能が制限される

#### 解決方法

**1. 権限の確認と設定**
```
手順:
1. 設定 > アプリ > VTuber Camera
2. 権限をタップ
3. 以下の権限を有効化:
   - カメラ
   - ストレージ
   - マイク（必要に応じて）
4. アプリを再起動
```

**2. Android版本別の対応**
```
Android 11以降:
- ファイルアクセス権限の個別設定
- スコープストレージへの対応

Android 10:
- レガシーストレージの有効化
- 権限の段階的な許可

Android 9以下:
- 従来の権限システム
- 一括権限の許可
```

### デバイス非対応

#### 症状
- 「このデバイスはARに対応していません」エラー
- ARモードが利用できない
- パフォーマンスが著しく低い

#### 解決方法

**1. 対応状況の確認**
```
確認方法:
1. ARCore対応デバイス一覧を確認
2. デバイスのスペックを確認
3. Android版本を確認（7.0以上必要）
```

**2. 代替手段**
```
非対応デバイスでの対処:
- 2Dモードでの撮影
- 静止画合成機能の利用
- 軽量版機能の使用
- デバイスのアップグレード検討
```

## 撮影と保存の問題

### 写真が保存されない

#### 症状
- 撮影ボタンを押しても写真が保存されない
- 「保存に失敗しました」エラー
- ギャラリーに表示されない

#### 解決方法

**1. ストレージの確認**
```
確認項目:
- 空き容量が十分か（1GB以上推奨）
- ストレージ権限が許可されているか
- 保存先フォルダが存在するか

対処方法:
- 不要なファイルを削除
- 権限設定を確認
- アプリを再起動
```

**2. ファイルシステムの問題**
```
対処方法:
- デバイスを再起動
- ストレージの整合性チェック
- 外部ストレージの確認
- 保存先の変更
```

### 写真の品質が悪い

#### 症状
- 画像がぼやける
- 色味がおかしい
- アバターが正しく合成されない

#### 解決方法

**1. 撮影環境の改善**
```
対処方法:
- 十分な照明を確保
- 手ブレを防ぐ
- 適切な距離を保つ
- 背景を整理する
```

**2. 設定の調整**
```
推奨設定:
- 解像度: 最高品質
- 照明調整: 自動または手動調整
- フォーカス: タップフォーカス使用
- HDR: 環境に応じて有効化
```

## 一般的な問題

### アプリがクラッシュする

#### 症状
- アプリが突然終了する
- 「応答していません」エラー
- 起動時にクラッシュする

#### 解決方法

**1. 基本的な対処**
```
手順:
1. アプリを完全に終了
2. デバイスを再起動
3. アプリを再起動
4. 最新版に更新
```

**2. 詳細な対処**
```
対処方法:
- キャッシュをクリア
- データをリセット（設定は失われます）
- アプリを再インストール
- デバイスの空き容量を確保
```

### 設定が保存されない

#### 症状
- アプリ再起動後に設定がリセットされる
- カスタマイズが反映されない
- アバターライブラリが空になる

#### 解決方法

**1. ストレージ権限の確認**
```
確認項目:
- ストレージ権限が許可されているか
- アプリデータの保存が許可されているか

対処方法:
- 権限設定を確認
- アプリの設定をリセット
- 再度設定を行う
```

**2. データ保護の設定**
```
対処方法:
- バックアップ設定を有効化
- 自動削除機能を無効化
- 手動でデータをエクスポート
```
