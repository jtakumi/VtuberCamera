# VRMファイル要件と推奨設定

## 概要

VTuber Camera アプリでVRMアバターを使用するための要件と推奨設定について説明します。最適なAR体験を得るために、これらのガイドラインに従ってVRMファイルを準備してください。

## VRMファイル要件

### 対応ファイル形式
- **ファイル形式**: VRM 0.0 および VRM 1.0
- **ファイル拡張子**: `.vrm`
- **最大ファイルサイズ**: 50MB
- **推奨ファイルサイズ**: 10MB以下（パフォーマンス最適化のため）

### 技術仕様
- **ポリゴン数**: 最大20,000ポリゴン（推奨10,000以下）
- **テクスチャ解像度**: 最大2048x2048px（推奨1024x1024px）
- **テクスチャ形式**: PNG、JPEG対応
- **ボーン数**: 最大100ボーン（推奨50以下）
- **ブレンドシェイプ**: 最大50個（表情制御用）

### 必須コンポーネント
- **メッシュデータ**: 3Dモデルの形状情報
- **マテリアル**: 表面の質感とテクスチャ情報
- **VRMメタデータ**: アバター情報とライセンス
- **ヒューマノイドボーン**: 標準的な人型ボーン構造

### オプションコンポーネント
- **表情データ**: BlendShape形式の表情制御
- **ポーズデータ**: 事前定義されたポーズ情報
- **物理演算**: 髪や服の揺れ物理（SpringBone）
- **アニメーション**: 基本的なアニメーションクリップ

## 推奨設定

### パフォーマンス最適化
```
ポリゴン数: 5,000-8,000（モバイル最適化）
テクスチャ: 512x512px（バッテリー効率重視）
ボーン数: 30-40（リアルタイム処理最適化）
マテリアル数: 5個以下（描画コール削減）
```

### 品質重視設定
```
ポリゴン数: 10,000-15,000（高品質表示）
テクスチャ: 1024x1024px（詳細表現）
ボーン数: 50-70（細かい動作制御）
マテリアル数: 10個以下（表現豊富）
```

### 表情制御推奨設定
- **基本表情**: 喜び、怒り、悲しみ、驚き、通常
- **目の制御**: まばたき、ウィンク、視線制御
- **口の制御**: あいうえお、笑顔、困り顔
- **眉の制御**: 上げ下げ、困り眉、怒り眉

## デバイス別推奨設定

### ハイエンドデバイス（Snapdragon 8 Gen 2以上）
- ポリゴン数: 15,000まで
- テクスチャ: 1024x1024px
- 高品質シェーダー使用可能
- 複数アバター同時表示可能

### ミッドレンジデバイス（Snapdragon 7 Gen 1クラス）
- ポリゴン数: 10,000まで
- テクスチャ: 512x512px
- 標準品質シェーダー推奨
- 単一アバター表示推奨

### エントリーデバイス（Snapdragon 6 Gen 1以下）
- ポリゴン数: 5,000まで
- テクスチャ: 256x256px
- 軽量シェーダー必須
- 最小限の表情制御

## VRMファイル作成ガイド

### 推奨3Dソフトウェア
1. **VRoid Studio**（初心者向け）
   - 無料で使いやすい
   - VRM出力に最適化
   - 自動最適化機能

2. **Blender + VRM Add-on**（上級者向け）
   - 高度なカスタマイズ可能
   - 詳細な最適化制御
   - プロフェッショナル品質

3. **Unity + VRM SDK**（開発者向け）
   - 完全な制御が可能
   - カスタムシェーダー対応
   - 高度な最適化

### 最適化のコツ
1. **ポリゴン削減**
   - 見えない面の削除
   - LOD（Level of Detail）の活用
   - 不要な頂点の統合

2. **テクスチャ最適化**
   - アトラステクスチャの使用
   - 圧縮形式の選択
   - 不要な透明度の削除

3. **マテリアル統合**
   - 同じ設定のマテリアルを統合
   - 不要なマテリアルの削除
   - シンプルなシェーダーの使用

## ライセンスと利用規約

### VRMメタデータ設定
- **作者名**: アバター制作者の名前
- **ライセンス**: 利用許可の範囲
- **商用利用**: 可否の明記
- **改変許可**: 改変の可否
- **再配布**: 再配布の可否

### 推奨ライセンス設定
```
Title: [アバター名]
Author: [制作者名]
Contact: [連絡先]
License: CC BY 4.0（推奨）
Commercial Use: OK
Modification: OK
Redistribution: OK with Attribution
```

## 品質チェックリスト

### 基本チェック
- [ ] ファイルサイズが50MB以下
- [ ] VRM形式で正しく出力されている
- [ ] メタデータが適切に設定されている
- [ ] テクスチャが正しく適用されている

### パフォーマンスチェック
- [ ] ポリゴン数が推奨範囲内
- [ ] テクスチャサイズが適切
- [ ] 不要なボーンが削除されている
- [ ] マテリアル数が最適化されている

### 機能チェック
- [ ] 基本表情が動作する
- [ ] ポーズが正しく適用される
- [ ] 物理演算が適切に動作する
- [ ] アニメーションが正常に再生される

## トラブルシューティング

### よくある問題
1. **ファイルが読み込めない**
   - ファイル形式の確認
   - ファイルサイズの確認
   - 破損チェック

2. **表情が動かない**
   - BlendShapeの設定確認
   - 命名規則の確認
   - ウェイトの設定確認

3. **テクスチャが表示されない**
   - テクスチャパスの確認
   - ファイル形式の確認
   - 解像度の確認

詳細なトラブルシューティングについては、[トラブルシューティングガイド](TROUBLESHOOTING.md)を参照してください。
