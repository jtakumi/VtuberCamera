# VTuber Camera - Product Overview

VTuber Camera is a modern Android camera application built with Jetpack Compose, designed specifically for content creators and the VTuber community. The app provides high-quality photo capture with real-time preview capabilities.

## Core Features
- Real-time camera preview with CameraX integration
- High-quality JPEG photo capture with auto-save to Pictures/VTuberCamera folder
- Seamless front/back camera switching with lens support (including ultra-wide)
- Flash control with 3 modes: OFF/ON/AUTO
- Zoom functionality via pinch gestures and button controls (0.5x to 10x range)
- Instant photo preview and delete functionality
- Device rotation support with automatic adjustment

## Target Audience
- VTuber content creators
- Mobile photography enthusiasts
- Users seeking a modern, responsive camera experience

## Design Philosophy
- Material Design 3 with dynamic color support
- Dark mode integration following system settings
- Declarative UI with Jetpack Compose
- Performance-focused: <2s startup time, <200ms capture response
- Internationalization support (English/Japanese)

## Technical Goals
- Android 15 compatibility with latest permission models
- Battery efficiency (95% compared to standard camera apps)
- Memory optimization (<200MB usage)
- 98% Android device compatibility through CameraX
