# Requirements Document

## Introduction

VTuber Camera アプリにVRMファイルのアバターモデルを読み込み、ARカメラ撮影でアバターと一緒に写真を撮影できる機能を追加します。この機能により、VTuberコンテンツクリエイターが自分のアバターと現実世界を組み合わせた写真を簡単に作成できるようになります。

## Requirements

### Requirement 1

**User Story:** VTuberクリエイターとして、自分のVRMアバターファイルをアプリに読み込んで、ARカメラでアバターと一緒に写真を撮影したい

#### Acceptance Criteria

1. WHEN ユーザーがVRMファイル選択ボタンをタップ THEN システムはファイルピッカーを表示してVRMファイルの選択を可能にする
2. WHEN 有効なVRMファイルが選択される THEN システムは3Dアバターモデルを読み込んでプレビュー表示する
3. WHEN VRMファイルの読み込みが失敗する THEN システムはエラーメッセージを表示して適切な対処方法を案内する
4. WHEN アバターが読み込まれた状態でARモードを開始する THEN システムはカメラプレビューにアバターを重ね合わせて表示する

### Requirement 2

**User Story:** ユーザーとして、ARカメラでアバターの位置、サイズ、向きを調整して理想的な構図で撮影したい

#### Acceptance Criteria

1. WHEN ARモードでアバターが表示されている THEN ユーザーはタッチジェスチャーでアバターの位置を移動できる
2. WHEN ピンチジェスチャーを行う THEN アバターのサイズを拡大・縮小できる
3. WHEN 回転ジェスチャーを行う THEN アバターの向きを360度回転できる
4. WHEN アバターの調整中 THEN リアルタイムでプレビューに反映される
5. WHEN 調整完了後に撮影ボタンをタップ THEN アバターが合成された写真が保存される

### Requirement 3

**User Story:** ユーザーとして、アバターの表情やポーズを変更して多様な表現で撮影したい

#### Acceptance Criteria

1. WHEN VRMアバターが読み込まれている THEN システムは利用可能な表情リストを表示する
2. WHEN 表情を選択する THEN アバターの表情がリアルタイムで変更される
3. WHEN VRMにポーズデータが含まれている THEN 利用可能なポーズリストを表示する
4. WHEN ポーズを選択する THEN アバターのポーズがリアルタイムで変更される
5. WHEN 表情とポーズが設定された状態で撮影する THEN 設定された状態で写真が保存される

### Requirement 4

**User Story:** ユーザーとして、複数のVRMアバターを管理して簡単に切り替えて使用したい

#### Acceptance Criteria

1. WHEN 複数のVRMファイルが読み込まれている THEN システムはアバターライブラリを表示する
2. WHEN アバターライブラリでアバターを選択する THEN 選択されたアバターがARカメラに適用される
3. WHEN アバターにカスタム名前を設定する THEN システムは名前を保存して表示する
4. WHEN 不要なアバターを削除する THEN システムはアバターをライブラリから削除する
5. WHEN アプリを再起動する THEN 以前に読み込んだアバターが保持されている

### Requirement 5

**User Story:** ユーザーとして、AR撮影時の照明や影の効果を調整してより自然な合成写真を作成したい

#### Acceptance Criteria

1. WHEN ARモードが開始される THEN システムは環境光を検出してアバターに適用する
2. WHEN 照明設定メニューを開く THEN ユーザーは明度、色温度、影の強さを調整できる
3. WHEN 照明設定を変更する THEN アバターの見た目がリアルタイムで更新される
4. WHEN 自動照明モードを有効にする THEN システムは環境に応じて自動的に照明を調整する
5. WHEN 撮影する THEN 設定された照明効果が適用された写真が保存される

### Requirement 6

**User Story:** ユーザーとして、ARアバター機能を使用する前に必要な権限と要件を理解して適切に設定したい

#### Acceptance Criteria

1. WHEN ARアバター機能を初回使用する THEN システムは必要な権限（カメラ、ストレージ、ARCore）を要求する
2. WHEN デバイスがARCoreに対応していない THEN システムは代替手段または制限事項を説明する
3. WHEN 権限が拒否される THEN システムは機能制限と権限付与方法を案内する
4. WHEN VRMファイルの要件を確認する THEN システムは対応ファイル形式とサイズ制限を表示する
5. WHEN パフォーマンス要件を満たさない THEN システムは推奨設定や制限事項を案内する
